# Qt Modbus RTU/TCP 工业设备监控与调试系统

这是一个使用 C++/Qt Widgets 开发的工业上位机项目，目标是实现 Modbus RTU/TCP 通信、寄存器读写、周期采集、实时曲线、报警记录、SQLite 历史数据存储和通信报文监视。

## 当前阶段

Task 1：初始化 Qt 工程。

当前已完成：

- 创建 Qt Widgets 主窗口
- 创建主要功能页入口
- 配置 CMake 构建
- 为后续模块预留目录结构

## 后续任务

1. 定义核心数据结构
2. 实现设备连接面板
3. 封装 Modbus 通信接口
4. 实现寄存器读写
5. 实现报文日志
6. 实现周期采集、实时曲线、报警和数据库
